# Contributing

Thank you for taking an interest in Trindle Folders. It is appreciated.

The way this project is set up, the code is written and kept in one place, so code changes from outside cannot be taken. That has nothing to do with the quality of anyone's work. It works best when we hear what went wrong and fix it ourselves.

So the most useful thing you can send is a description:

- **Something broken?** Report bugs and crashes on the [Buildmorphic community](https://trindle.buildmorphic.com). Say what you did, what you expected, and what happened instead. The version, and the kind of place (a folder, an archive, a drive, a network share or a phone), help a great deal. A picture of the window is welcome.
- **An idea?** Say what you were trying to do and where Folders got in the way. You do not need to suggest the fix.
- **A security problem?** Please use private reporting rather than a public issue. [SECURITY.md](SECURITY.md) explains how.
